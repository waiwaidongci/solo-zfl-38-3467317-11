# 古船模型帆索校准

运行：

```bash
npm start
```

访问`http://localhost:3038`。数据保存在`data/model-rigging-calibration.json`（可用环境变量`PORT`、`DB_PATH`覆盖）。

## 吊装配平

每艘船可登记：整船质量（kg）、重心坐标（x, y, z）、各吊点位置（x, y, z）与对应吊索额定载荷（kg）。选择吊点组合与吊高（吊钩高度 z）后，按重力平衡计算：

- **每根吊索受力**：所有吊索汇交于重心投影正上方的吊钩，解静力平衡方程 `Σ Tᵢ·dᵢ = (0,0,W)`。三点为静定精确解，两点为杠杆解（重心投影须落在两吊点连线上），四点及以上为静不定、取最小范数平衡解。质量与受力均按公斤计（kgf 与 kg 数值一致）。
- **水平夹角**：吊索与水平面夹角 `atan2(高差, 水平距离)`。
- **重心投影**：重心在水平面的 (x, y)，须落在吊点组成的支撑多边形（凸包）内。

出现以下情况时拒绝（计算与确认都会返回全部拒绝原因，且页面展示已算出的受力）：

- 吊索受力超过额定载荷；
- 水平夹角超过 60°；
- 重心投影落在支撑多边形外（含吊索受压的几何）；
- 吊点重复；
- 几何数据缺失（质量/重心/吊高/吊点坐标/额定载荷未登记或无效）。

通过后若受力达额定载荷 80% 以上、或夹角达 55° 以上，方案标记为**危险**（危险项逐条列出），否则为**安全**；方案记录可按风险筛选。

### 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| PUT | `/api/items/:id/lifting` | 登记/更新整船质量与重心（保留已登记吊点） |
| POST | `/api/items/:id/lifting/points` | 新增吊点（名称重复返回 409） |
| POST | `/api/items/:id/lifting/calculate` | 试算，不落库；返回 `{ok, reasons, plan}` |
| POST | `/api/items/:id/lifting/plans` | 确认方案：校验失败 422；相同吊点组合+吊高重复确认 409（并发确认只生成一个方案）；成功 201 |

### 可靠性

- 写入串行化且原子：先写临时文件再 rename，磁盘上只有完整旧版或完整新版；保存失败时内存同步回滚，不留半套数据。
- 确认的去重检查与写入之间无 await，在单线程事件循环中原子完成，并发确认只生成一个方案。
- 记录持久化在 JSON 文件中，服务重启后保留；已有模型、任务、日志与方案不受影响。

## 测试

```bash
npm test            # 单元（安全/超载/偏心/夹角/重复/缺数据）+ 集成（并发/原子写/重启保留/已有数据不变）+ 浏览器验收
npm run acceptance  # 仅浏览器验收（Playwright + Chromium）
```

测试入口为显式文件列表（`node --test test/lifting.test.mjs test/api.test.mjs test/acceptance.test.mjs`），Node 20 与 Node 22 均可运行（Node 22 不再接受 `node --test test/` 裸目录写法）。浏览器验收需要 Chromium 系统依赖；无 root 权限的环境可执行`scripts/install-browser-deps.sh`（下载 deb 解压到`.browser-sysroot/`，验收脚本自动经`LD_LIBRARY_PATH`加载）。
